## 核心思路

大多数编辑器把命令放进菜单，你靠**读**找到它。Vim 把命令放在键上，你靠
**知道自己想干什么**找到它。

这套配置把这一点做到底。每次按键，第一下就在回答一个问题：

| 你想…… | 按 | 因为它的含义是 |
|---|---|---|
| 去别的地方 | `;` | "哪个文件 / 符号 / 位置？" |
| 改眼前的代码 | `,` | "对它做什么？" |
| 调整屏幕布局 | `s` | "这个窗口怎么办？" |
| 用语言相关的功能 | `\` | "**当前文件类型**有什么？" |
| 其他一切 | `<Space>` | git、测试、调试、AI…… |

**没有一个键是按插件归类的。** `;f` 就是找文件，不管背后是 picker、文件树还是别的——
你按它是因为你想要一个文件，不是因为你记得某个插件名。

两个直接后果：

- **天天用的是两键。** 找文件、格式化、跳定义。少用的才允许长一点。
- **一个键只有一个含义。** `,` 是"改这段代码"，那找文件就永远不在 `,` 下面，
  哪怕字母再顺手。

## 五分钟 Vim 入门

已经会 Vim 的跳过这节。

Vim 有**模式**。这是全部诀窍，也是唯一一开始会别扭的地方。

| 模式 | 你在做什么 | 怎么进 | 怎么出 |
|---|---|---|---|
| **Normal** | 下命令 | `Esc`，或 `jk` | — |
| **Insert** | 打字 | `i` | `Esc` 或 `jk` |
| **Visual** | 选择 | `v` | `Esc` |

打开就是 Normal 模式。字母是命令，不是文字。`d` 删除、`y` 复制、`p` 粘贴。
要打字先按 `i`。

**快速连打 `jk` 等于 Esc。** 它在home row 上，你会一直用它。

移动：

```
h j k l    左 下 上 右
w  b       下/上一个词
0  $       行首 / 行尾
gg  G      文件开头 / 结尾
```

**撤销是 `u`，重做是 `Ctrl-r`。** 大胆试，随时能退回来。

会这些就能活下来了。下一节才是 Vim 值得学的原因。

## 语法

Vim 不是一堆要背的快捷键，它是一门小语言——**你没学过的命令，是可以推导出来的**。

每一次编辑都是同一个形状：

```
操作符  +  次数  +  目标
  d         2        w      删两个词
  c         _        i(     改括号里的内容
  y         3        j      复制这行和下面 3 行
```

### 操作符——做什么

| | |
|---|---|
| `d` | 删除 |
| `c` | 修改（删掉然后进入插入模式） |
| `y` | 复制 |
| `>` `<` | 增加 / 减少缩进 |
| `gu` `gU` | 转小写 / 大写 |
| `gc` | 注释 |
| `=` | 自动缩进 |

### 目标——对什么做

目标要么是**动作**（从这里到那里），要么是**文本对象**（不管光标在里面哪个位置，
整个这一块）。

**动作**从光标向外延伸：

```
dw     删到下一个词的开头
d$     删到行尾
d0     删到行首
dG     删到文件结尾
d}     删到下一个空行
df,    删到下一个逗号（含逗号）
dt)    删到下一个 ) 之前（不含）
```

**文本对象**不关心光标在里面的哪个位置。它们取 `i`（inside，内部）
或 `a`（around，含边界）：

```
di(    删括号里的内容      foo(bar) → foo()
da(    连括号一起删        foo(bar) → foo
ci"    改引号里的内容
dit    删 HTML/XML 标签里的内容
dap    删这一整段
```

`i` 和 `a` 的区别是这里最值钱的一条：

```
"hello world"        光标在里面任意位置

ci"   →  ""          保留引号，直接开始打新内容
ca"   →              连引号一起拿掉
```

### 语法级对象

这份配置接了 treesitter，所以目标可以是**真正的代码结构**，而不只是成对符号：

| 目标 | 是什么 |
|---|---|
| `if` / `af` | **函数**的内部 / 整个函数 |
| `ic` / `ac` | **类**的内部 / 整个类 |
| `ia` / `aa` | **参数**（`daa` 会连它的逗号一起删） |
| `io` / `ao` | **块**、条件分支、循环体 |

```
dif    删掉这个函数的函数体，光标在函数里任意位置都行
daf    删掉整个函数
caa    改这个参数
vio    选中这个 if 的分支体
```

`daa` 特别值得留意：手动删参数总会留下一个多余的逗号，而参数对象知道分隔符
的存在，会一起带走。

### 为什么这件事重要

你不需要"学会 `dif`"。你学的是 `d`，和 `if`，这个组合自然就成立了——
连带 `cif`、`yif`、`>if`、`gcif`、`vif` 也一起会了。
**6 个操作符 × 20 个目标 = 120 个你从没背过的命令。**

想做一件新事情时，只问两个问题：*什么操作？* 和 *作用在什么上？*
然后按这个顺序打出来。

### 几个只是缩写的键

```
x   = dl      删一个字符          D   = d$    删到行尾
s   = cl      改一个字符          C   = c$    改到行尾
dd  = d_      删这一行            cc  = c_    改这一行
```

**操作符双击**（`dd`、`yy`、`cc`、`gcc`）永远表示"这一行"。

## 五个前缀

```
;  去某处              ,  改这段代码
s  窗口                \  仅当前文件类型
<Space>  其余一切
```

按下任意一个，**等半秒**——会弹出菜单列出可用的键。你不需要背这份文档，
菜单本身就是文档。

任何时候按 `<Space>?` 打开一页速查表。

## 去某处：`;`

所有"到达某个文件、符号或位置"的方式。

### 文件

| 键 | 作用 |
|---|---|
| `;<Space>` | **智能查找**——最近 + 已开 + 全部文件，按你的使用频率排序。**从这个开始。** |
| `;f` | 按文件名找 |
| `;F` | 在当前文件所在目录找 |
| `;r` | 最近打开过的 |
| `;b` | 已打开的 buffer |
| `;g` | git 跟踪的文件 |
| `;n` | 这份 Neovim 配置里的文件 |
| `;p` | 切换项目 |
| `;a` | **交替文件**——在最近两个文件之间来回。改实现/改测试的循环。 |
| `;;` | 重开上次的搜索，结果列表原样保留 |

`;<Space>` 是最该养成习惯的一个：它会学习你常碰哪些文件并排到最前。

### 文本与符号

| 键 | 作用 |
|---|---|
| `;/` | 全项目搜索 |
| `;w` | 搜光标下的词 |
| `;l` | 在当前文件里按行找 |
| `;D` | 搜当前目录 |
| `;s` | 当前文件的符号（函数、类） |
| `;S` | 全项目符号 |
| `;c` | **谁调用了它**——光标下符号的调用方 |

### 浏览

| 键 | 作用 |
|---|---|
| `;e` | 文件树侧栏 |
| `;d` | 浏览当前文件所在目录 |
| `;o` | **oil**——把目录当文本编辑（见下） |
| `-` | 用 oil 打开上级目录 |

### 钉住的文件

| 键 | 作用 |
|---|---|
| `;H` | 钉住当前文件 |
| `;h` | 查看钉住列表 |
| `;1` … `;9` | 直达第 1-9 个 |

把正在改的三四个文件钉住，之后 `;2` 不用看屏幕就能过去。换任务时重新钉。

### 位置

`;j` 跳转表 · `;m` 标记 · `;t` TODO · `;T` TODO/FIX/FIXME

## 改代码：`,`

所有**对**眼前代码执行的操作。

| 键 | 作用 |
|---|---|
| `,a` | **Code action**——修复菜单（补 import、快速修复） |
| `,f` | 格式化 |
| `,r` | 重命名符号，全项目生效，带实时预览 |
| `,n` | 生成文档注释 |
| `,x` | 运行当前文件 |
| `,O` | 当前文件大纲 |

`,a` 和 `,r` 只在有语言服务器的地方存在——纯文本文件里它们根本不出现。

### 移动行

| 键 | 作用 |
|---|---|
| `,j` / `,k` | 把当前行（或选区）下移 / 上移 |
| `,h` / `,l` | 减少 / 增加缩进 |

对 Visual 选区同样有效。

### 重构

| 键 | 作用 |
|---|---|
| `,ef` | 把选区提取成函数 |
| `,ex` | 提取成变量 |
| `,eb` | 提取成块 |
| `,i` | 内联变量 |
| `,R` | 所有重构操作的菜单 |
| `,w` | 替换光标下的词 |
| `,F` | 完整的搜索替换面板 |

`,e*` 系列作用于 Visual 选区。

## 窗口：`s`

| 键 | 作用 |
|---|---|
| `ss` | 下方分屏 |
| `sv` | 右侧分屏 |
| `sd` | 关闭当前窗口 |
| `so` | 关闭其他所有窗口 |
| `sw` | 上一个窗口 |
| `se` | 跳到编辑器区域 |
| `s=` | 均分大小 |
| `sm` | 缩放 / 还原 |

**窗口之间移动不用 `s`**——那是一个键：

```
Ctrl-h  Ctrl-j  Ctrl-k  Ctrl-l     左 下 上 右
Ctrl-,                             直达编辑器，再按跳回
```

它们**在终端内部也能用**——当 AI 面板或 shell 开在代码旁边时，这一点很关键。

## 当前文件类型：`\`

`\` 放的是只在当前文件里有意义的操作。同一个键在不同文件类型下含义不同，
这正是它的用途。

| 文件类型 | 键 |
|---|---|
| Go | `\o` 整理 import · `\G` 重建 gopls 索引 |
| Python | `\o` 整理 import · `\v` 选择虚拟环境 |
| C/C++ | `\h` 在源文件和头文件间切换 |
| Markdown | `\p` 切换预览 |
| LaTeX | `\b` 编译 · `\v` 看 PDF · `\t` 目录 · `\e` 错误 · `\k` 清理 |
| Diffview | `\e` 聚焦文件面板 · `\co` / `\ct` 解决冲突（用我方/对方） |

按 `\` 等一下，就能看到当前文件提供了什么。

## 其余：`<leader>`

`<leader>` 就是 **空格键**。按下等一秒，每个字母是一个分组。

| 键 | 分组 | 内容 |
|---|---|---|
| `<Space>g` | Git | 状态、blame、hunk、lazygit（`gg`）、diffview |
| `<Space>G` | GitHub | PR、issue、review |
| `<Space>d` | 调试 | 断点、单步、查看变量 |
| `<Space>t` | 测试 | 跑文件 / 跑最近的 / 调试、输出面板 |
| `<Space>x` | 诊断 | 错误列表、quickfix、location list |
| `<Space>a` | AI | Claude / Codex 面板、prompt、transcript |
| `<Space>b` | Buffer | 删除、固定、关其他 |
| `<Space>m` | 管理 | help、man、键位、Lazy、Mason、LSP 状态 |
| `<Space>s` | 会话 | 保存 / 恢复工作布局 |
| `<Space>y` | 复制 | 复制文件路径、yank 历史、寄存器 |
| `<Space>u` | 开关 | 换行、拼写、诊断、配色 |
| `<Space><Tab>` | Tab | tab page |
| `<Space>q` | 退出 | 全部退出 |

## 工作流

### 读陌生代码

```
;/  搜一个你认得的词
gd  跳到定义
gd  再跳，再跳——顺着往下追
Ctrl-o  原路返回
;c  谁调用了它？
]]  当前文件里这个符号的下一处
```

`K` 显示光标下内容的文档，`gr` 列出所有引用。

### 编辑循环

```
;<Space>   打开文件
,a         让语言服务器修掉能修的
,f         格式化
<Space>tf  跑这个文件的测试
```

在两个文件之间来回用 `;a`；三四个文件就用 `;H` 钉住，然后 `;1`-`;4`。

### 整理文件

`;o` 把目录**当成可编辑的 buffer** 打开。它就是普通 Vim buffer：

```
改一行的文件名        → 重命名
dd，到别处 p          → 移动文件
写新的一行            → 新建（末尾加 / 就是目录）
dd                    → 删除
:w                    → 确认列表，执行
```

用这种方式移动 `.go` / `.ts` 文件时会通知语言服务器，**引用它的 import 会被自动改写**，
不会悄悄断掉。

### Git

`<Space>gg` 打开 lazygit——暂存、提交、历史都在一处。
`<Space>gv` 打开 diffview 做分支 review。在 diffview 内部，`\` 是它自己的操作，
`<Space>gq` 关闭。

### 终端与 AI

```
Ctrl-/       切换终端
Ctrl-1 … 9   直达第 1-9 个终端，在另一个终端里也能按
<Space>ac    打开 AI 面板
<Space>ai    在真正的 Neovim buffer 里写 prompt
```

`Ctrl-]` 退出终端输入但不打扰里面运行的程序——因为 `Esc` 属于 AI CLI 自己。

## 忘了键位怎么办

1. **按下前缀然后等。** `;`、`,`、`s`、`\`、`<Space>` 停顿一下都会弹菜单。最快。
2. **`<Space>?`** —— 一页列出所有前缀和常用键。
3. **`<Space>mk`** —— 按描述搜索所有键位。
4. **`;;`** —— 搜索结果列表丢了，用它原样找回来。

那些菜单是**从配置本身生成的**，不会像文档一样过期。
